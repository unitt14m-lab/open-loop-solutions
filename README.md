# Open Loop Arabia

You are an expert UI/UX designer and web developer. Build a professional, modern, responsive Arabic landing page and multi-page architecture for "أوبن لوب | Open Loop" (a marketing and consultancy firm for the non-profit sector in Saudi Arabia). 

### GENERAL REQUIREMENTS:

1. RTL Support: Fully aligned for Right-To-Left (Arabic) language layout.

2. Styling: Professional, modern, non-profit / corporate tech aesthetic. Clear typography, high contrast, clean component cards, smoothly rounded edges, and visually separated sections.

3. Header Layout:

   - Left Side: Company Logo (Open Loop).

   - Right Side: Navigation Bar with links: (الرئيسية، عن أوبن لوب، الخدمات، الباقات، تطوع معانا، انضم إلينا، احجز استشارتك).
